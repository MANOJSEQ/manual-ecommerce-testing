# DemoBlaze Customer Journey Test Plan

## 1. Objective

Manually test important customer journeys on the DemoBlaze e-commerce website and document the results clearly.

Website: https://www.demoblaze.com/

## 2. Features in Scope

- Homepage and product categories
- Product details
- User sign-up
- User login and logout
- Shopping cart
- Product removal
- Purchase form
- Order confirmation
- Form validation
- Basic accessibility checks

## 3. Out of Scope

- Real payment processing
- Database testing
- Performance testing
- Mobile application testing
- Admin functionality

## 4. Testing Types

- Functional testing
- Positive testing
- Negative testing
- Boundary-value testing
- Exploratory testing
- Usability testing
- Basic accessibility testing
- Regression testing

## 5. Test Environment

- Application: DemoBlaze
- Browser: Google Chrome
- Device: MacBook
- Operating system: macOS
- Tester: Manoj Sequeira

## 6. Entry Criteria

Testing can begin when:

- The DemoBlaze website is available
- The browser has internet access
- Test scenarios have been prepared

## 7. Exit Criteria

Testing is complete when:

- All planned test cases have been executed
- Test results have been recorded
- Identified defects have been documented
- A test summary report has been created

## 8. Risks

- The public demo website may be unavailable
- Existing test data may affect results
- Website behaviour may change without notice
- No access is available to the application database or requirements
