# DemoBlaze Customer Journey Requirements

These requirements were created from observing the public DemoBlaze website because official business requirements were not provided.

## RQ-01: Browse Products

A customer should be able to view available products and filter them by category.

### Acceptance Criteria

- Products are displayed on the homepage
- Categories include Phones, Laptops and Monitors
- Selecting a category displays relevant products

## RQ-02: View Product Details

A customer should be able to open a product and view its name, price and description.

### Acceptance Criteria

- The selected product page opens
- Product information is displayed
- An Add to cart button is available

## RQ-03: User Sign-up

A new customer should be able to create an account using a unique username and password.

### Acceptance Criteria

- Valid details create an account
- Duplicate usernames are rejected
- Empty required fields are not accepted

## RQ-04: User Login

A registered customer should be able to log in using valid credentials.

### Acceptance Criteria

- Valid credentials log the customer in
- Invalid credentials display an error
- The logged-in username is displayed

## RQ-05: Manage Shopping Cart

A customer should be able to add and remove products from the cart.

### Acceptance Criteria

- Added products appear in the cart
- The correct product name and price are displayed
- A product can be removed
- The total updates correctly

## RQ-06: Complete a Purchase

A customer should be able to purchase products using valid customer details.

### Acceptance Criteria

- The purchase form accepts valid details
- A confirmation message appears
- The confirmation includes an order ID and amount

## RQ-07: Validate Purchase Information

The purchase form should prevent submission when required information is missing or invalid.

### Acceptance Criteria

- Required fields are clearly identified
- Missing required information displays a helpful message
- Invalid payment information is rejected
